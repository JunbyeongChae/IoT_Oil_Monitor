# ⛽ 스마트 오일 탱크 잔량 모니터링 시스템 (IoT Oil Tank Level Monitor)

## 📌 프로젝트 요약 (Summary)

### 문제 정의

기존 단독주택 기름보일러의 잔량 확인 방식(수동, 외부에 위치)은 번거롭고, 겨울철 연료 부족 시점에 예측이 어려워 불편함이 컸습니다. 특히, 본 프로젝트의 대상 탱크는 깊이 **1200mm**로 일반적인 센서 적용에 한계가 있었습니다.

### 해결책 및 핵심 목표

ESP32 기반의 IoT 시스템을 구축하여 **실시간 원격 모니터링**을 구현하고, **실외 환경에 최적화된 방수 설계(풀옵션 패키징)**를 통해 잔량 확인의 불편함을 근본적으로 해소합니다.

---

## ✨ 주요 기능 (Features)

* **실시간 잔량 모니터링:** 1호기(센서)가 2호기(실내 디스플레이)로 ESP-NOW를 통해 직접 전송, TFT 게이지 화면에 잔량(%) 실시간 표시.
* **텔레그램 원격 확인/제어:** `/status`(상태 조회), `/reboot`(재부팅), `/update [URL]`(원격 OTA)를 텔레그램 봇으로 실행.
* **잔량 부족 알림:** 잔량이 **15% 이하**로 떨어질 시 텔레그램 푸시 알림 자동 발송(25% 회복 전까지 중복 알림 없음).
* **비접촉식 고정밀 측정:** AJ-SR04M 방수 초음파 센서를 활용하여 깊이 122cm의 탱크 잔량을 정확하게 측정(5회 중앙값 필터).
* **실외 환경 내구성:** IP66 방수 정션 박스 및 케이블 글랜드를 적용한 풀옵션 패키징 설계.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 구성 요소 | 상세 스펙 |
| :--- | :--- | :--- |
| **마이크로컨트롤러** | ESP32-WROOM-32 x2 | 1호기(센서, C-Type 38핀), 2호기(실내 디스플레이) |
| **센서** | AJ-SR04M | 방수형 초음파 모듈 (측정 거리 2cm ~ 450cm) |
| **개발 언어** | C++ | Arduino Sketch (PlatformIO) |
| **장치 간 통신** | ESP-NOW | 1호기 → 2호기 실시간 데이터 전송 (같은 Wi-Fi 채널 필요) |
| **원격 알림/제어** | Telegram Bot | 저잔량 알림, 상태 조회, 원격 재부팅/OTA |
| **디스플레이** | TFT_eSPI (ST7789, 240x240) | 원형 게이지 UI, 온라인/오프라인 표시 |
| **전원** | USB-C Power | 5V 3A 어댑터 및 20AWG C-Type 케이블 |
| **하드웨어 설계** | IP66, 38핀 스크류 터미널 쉴드 | 실외 환경 최적화 및 견고한 결선 |

## 🚀 구현 및 설치 과정 (Assets Preview)

****

1.  **초기 기능 구현:** 브레드보드를 이용해 ESP32와 AJ-SR04M 센서를 연결하고, ESP-NOW 통신 및 잔량 계산 알고리즘을 구현하여 기능 검증 (로드맵 Phase 2).
2.  **최종 패키징:** 38핀 스크류 쉴드를 사용해 영구적인 결선을 완료하고, ABS 방수 박스에 조립 후 케이블 글랜드 및 실리콘으로 완벽 방수 처리 (로드맵 Phase 3).
3.  **현장 설치 및 모니터링:** 기름통 상단에 센서를 고정하고 전원을 연결하여, 실내 디스플레이와 텔레그램으로 잔량을 실시간으로 모니터링 시작.
